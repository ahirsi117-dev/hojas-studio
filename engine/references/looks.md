# الطوابع (Looks) والأساليب البصرية

`hs look <work> list` · `hs look <work> apply <اسم>` · `hs look <work> off`. وبالاستوديو: «الملفات» ← «الطابع».

الطابع يغيّر مرة وحدة: طبقة ملمس فوق المقطع (`look.overlay`) · تلوين الفيديو (`grade`) · لون وزخرفة كروت الشرح (`cardDefault`، وتتطبّق على الكروت الموجودة) · ألوان الكابشن · نوع الانتقال التلقائي. التعريفات في `looks.json` بمجلد السكل.

## الطوابع الجاهزة

| الاسم | متى |
|---|---|
| `dossier` ملف سري | تحقيق، معلومة مخفية، قصة جريمة أو فضيحة تقنية |
| `keynote` كينوت داكن | إطلاق منتج، أرقام، تقنية |
| `riso` ريزو مطبوع | محتوى مرح، تعليمي خفيف |
| `swiss` سويسري نظيف | محتوى مهني، لينكدإن |
| `hud` هولوقرام | ذكاء اصطناعي، مستقبل، مواصفات |
| `silent` سينما صامتة | تاريخ، قصة قديمة، كوميديا |
| `anime80` أنمي الثمانينات | ألعاب، شباب، حماس |
| `blueprint` مخطط أزرق | شرح هندسي، خطوات بناء |
| `luxury` فخامة ذهبية | فنادق، مطاعم فاخرة، عطور |
| `whiteboard` سبورة | دروس، قدرات، شرح بسيط |
| `mashrabiya` مشربية | تراث، مقاهي، محتوى محلي |
| `fanous` فانوس رمضان | رمضان والأعياد |
| `gameshow` برنامج مسابقات | مسابقات، تحديات، ترتيب، مراجعة السنة |
| `crt` شاشة طرفية | برمجة، أدوات مطورين، خيال علمي |
| `briefing` تقرير استخباري | أخبار، جغرافيا، تحليل أرقام بجدية |
| `spy` أفلام الجواسيس | مقدمات، تشويق، إعلان قبل إطلاق |

قواعد: طابع واحد بالمقطع. لو المستخدم اختار ألوان حسابه بصفحة الأسئلة، الطابع يغيّر الكابشن والكروت، فاسأله بسؤال مخصص قبلها أو خلّ ألوانه وطبّق التلوين والملمس بس (`hs set <work> grade.preset=warm look.overlay=grain`).

## تلوين الفيديو (`grade`)

`natural · skin · studio · warm · cool · night · muted · pop · teal · bw · film` و `grade.amount` من 0.2 إلى 1. يتطبّق على الفيديو بس. `skin` و`studio` أنسب شي لمقاطع الكلام للكاميرا.

## الكولاج الورقي (`type=collage`)

صور تتحول قصاصات أبيض وأسود منقّطة بحد كريمي وظل، وتتركّب من شاشة فاضية على خلفية لون واحد. فكرة gbro-collage-broll (MIT) لكن **بدون أي API**:
1. اطلب من ChatGPT بحسابه كل عنصر لوحده «صورة واحدة بخلفية شفافة PNG» (`hs gen request image`)، أو صور حقيقية من `hs media`.
2. `hs layer <work> add type=collage s=… e=… items='[{"src":"assets/a.png"},{"src":"assets/b.png"}]' bgColor="#E07A3F"`.
3. لون الخلفية له معنى: برتقالي = وقت واستعجال · خردلي = أدوات وتنبيه · أخضر غامق = تفكير · بنفسجي = ذكريات وعادات · تركوازي = قرار وفريق.
4. 3 إلى 6 عناصر كبيرة، بدون كتابة داخل الصور. مدة 3 إلى 5 ث على جملة وحدة.

## كتالوج 43 أسلوب (lemo-opuscar، MIT) كمرجع للأفكار

[ط] = ينفع طابع لمقطع كلام · [ف] = فيلم كود كامل بدون شخص (هذا لسكل Hojas Motion).

- **رسم يدوي:** crayon-book طباشير على ورق [ف] · watercolor ألوان مائية تنرسم [ف] · ink-wash حبر على ورق رز [ف] · impasto زيت بالسكين [ف] · one-line خط واحد ما ينقطع [ف، ط للكروت] · whiteboard سبورة بخط اليد [ط] · urban-sketch رسم مدن بقلم [ف].
- **تقاليد شرقية:** shadow-puppet خيال ظل [ف] · ukiyoe طباعة يابانية [ف] · papercut-red قص ورق أحمر [ف] · paper-lantern فانوس ورق [ف].
- **طباعة:** risograph ألوان مطبوعة مزاحة [ط] · halftone-dossier ملف بنقاط وختم [ط] · woodcut حفر خشب [ف] · engraving نقش نحاس [ف] · silkscreen-poster طباعة شاشة طبقة طبقة [ط، ف].
- **جرافيك وخط:** swiss-motion شبكة وخط واحد ولون واحد [ط] · spy-titles عناوين أفلام الستينات [ط للهوك] · art-deco أسود وذهبي [ط] · blueprint مخطط أبيض على أزرق [ط] · stained-glass زجاج معشّق [ف] · pictogram-motion رموز على الإيقاع [ط، ف] · ascii-crt حروف على شاشة قديمة [ط كمؤثر].
- **معلومات:** dataviz رسم بياني ينرسم [ط] · iso-infographic مكعبات متساوية [ط، ف] · dark-keynote كينوت داكن [ط] · living-screencast شخصية داخل واجهة حقيقية [ط] · hologram-hud واجهة مستقبلية [ط].
- **كرتون:** rubber-hose كرتون الثلاثينات [ف] · cel-anime-80s أنمي الثمانينات [ط] · scifi-toon خيال علمي [ف] · midcentury-toon كرتون الخمسينات للخطوات [ط للكروت].
- **ألعاب:** pixel-rpg بكسل وصناديق كلام [ط للهوك] · hd-2d بكسل بمجسم [ف] · microgame ألعاب صغيرة سريعة [ط للهوك] · game-show برنامج مسابقات [ط].
- **سينما:** silent-film فيلم صامت [ط] · backrooms تصوير كاميرا قديمة [ط كمؤثر].
- **مجسمات:** brick-toy مكعبات ألعاب · paper-popup كتاب منبثق · tilt-shift مدينة مصغرة · lowpoly-island جزيرة مضلعة · glass-product منتج زجاجي [كلها ف، تحتاج كرت شاشة].

نسخ محلية مقترحة: papercut ← مشربية · paper-lantern ← فانوس رمضان · ink-wash ← خط عربي بالفرشاة · ukiyoe ← زخرفة المخطوطات الإسلامية.
