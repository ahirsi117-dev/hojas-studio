# مقاطع من حلقة طويلة: بودكاست مترجم (4.3)

اقرأ هذا الملف لما يرسل حلقة طويلة (بودكاست، مقابلة، محاضرة) ويبي منها مقاطع قصيرة، أو يقول «ترجمها»، أو يختار «بودكاست مترجم» بصفحة الأسئلة.

**الشكل:** المقطع عمودي على المتحدث. فوق عنوان قصير بالعربي وتحته سطر المصدر («ديفيد قوقنز من Modern Wisdom»). وتحت الترجمة العربية بخط صغير نظيف يبان على أي خلفية، وتحتها الكلام الأصلي بالإنجليزي أصغر. **بدون موشن ولا زووم ولا مؤثرات ولا شريط تقدم.** كروت الشرح بس لو اختارها بصفحة الأسئلة.

## الخطوات

1. **فرّغ الحلقة كاملة** (مرة وحدة):
   ```bash
   hs clips scan <الحلقة.mp4> <مجلد المقاطع> [--model medium] [--lang en]
   ```
   ياخذ وقت (تقريباً دقيقة لكل دقيقة بالحلقة). شغّله بالخلفية وقل له كم يتوقع. يطلع `transcript.txt` بالتوقيت.

2. **اختر اللحظات بنفسك.** اقرأ النص كامل، واختر أقوى 3 إلى 5 لحظات:
   - 30 إلى 90 ثانية كل وحدة.
   - تبدأ بجملة تشد بدون مقدمة («المشكلة إنك…»، رقم، سؤال)، وتنتهي بفكرة مكتملة. لا تقطع بنص جملة.
   - كل لحظة تنفهم لحالها بدون باقي الحلقة.
   - اعرضها عليه بسطر لكل وحدة (الوقت + ليش اخترتها) قبل ما تقص، إلا لو قال «اختر أنت».

3. **قص كل لحظة لمشروع:**
   ```bash
   hs clips make <مجلد المقاطع> --from 12:30 --to 13:45 --title "كيف تبني ثقة حقيقية؟" --credit "ديفيد قوقنز من Modern Wisdom"
   ```
   يطلع مجلد مشروع جاهز فيه الفيديو والتفريغ (a.json و fixes.json) وأسلوب البودكاست مشغّل. **لا تعيد التفريغ.**
   - العنوان: سؤال أو وعد قصير (6 كلمات بالكثير) من فكرة المقطع.
   - المصدر: اسم الضيف «من» اسم البرنامج. لو ما تعرفه اكتب اسم البرنامج بس.

4. **كمّل كل مشروع بالخطوات العادية** (MONTAGE.md من الخطوة 3): خطة القص، صحّح fixes.json، `02_captions.py`، `hs caps regroup <work> words=7 dur=3`، القص والزوم (يقص عمودي على الوجه لحاله)، الفريمات، `hs patch`.
   - خطة القص: لا تشيل أنفاس المتحدث. البودكاست يبي إيقاعه الطبيعي.

5. **الترجمة:**
   ```bash
   hs tr <work> export > tr.json      # لكل جملة: src (الأصل) و tr (فاضي)
   # اكتب بخانة tr الترجمة العربية
   hs tr <work> import tr.json
   ```
   - فصحى سهلة وقصيرة تنقرا بنظرة. نفس المعنى بالضبط، لا تزيد ولا تشرح.
   - الأسماء والمصطلحات المعروفة تبقى مثل ما تنقال («Modern Wisdom»).
   - لو المقطع عربي أصلاً: `pod.lang=ar`، والترجمة تصير إنجليزي تحت (اختياري).

6. **صفحة الأسئلة:** اسأله مرة وحدة بأول مشروع (`brief ask`). `clips make` ينسخ إجاباته لباقي المقاطع لو حطيت `brief.json` بمجلد المقاطع.

7. **عاين** 3 لحظات على الأقل من كل مقطع، وتأكد إن الترجمة ما تغطي الوجه والعنوان ما يطلع برا الشاشة.

## الإعدادات (كلها تتعدل من الاستوديو، تبويب المشروع)
| المفتاح | وش يسوي |
|---|---|
| `pod.title` · `pod.credit` | العنوان والمصدر |
| `pod.tsize` · `pod.ty` | حجم العنوان ومكانه (نسبة من فوق) |
| `pod.lang` | `en` الأصل إنجليزي والترجمة عربي · `ar` الأصل عربي |
| `pod.orig` | يطلع الأصل تحت الترجمة أو لا |
| `pod.subScale` | حجم الأصل نسبة لحجم الترجمة |
| `pod.bar` | شريط التقدم (مطفي افتراضياً) |
| `cap.size` · `cap.y` · `cap.font` · `cap.bg=box` | حجم الترجمة ومكانها وخطها، وصندوق شفاف وراها لو الخلفية فاتحة |
